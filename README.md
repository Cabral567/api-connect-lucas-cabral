# API Connect - Gerenciamento de Usuários

## Visão Geral do Projeto
A **API Connect** é uma solução back-end desenvolvida com foco no padrão arquitetural RESTful para cadastro, listagem, busca, atualização e remoção de usuários. O projeto foi projetado como um MVP escalável com validação defensiva de entrada e manipulação rigorosa dos códigos de status HTTP.

## Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Framework Web:** Flask
* **Persistência de Dados:** Coleção em memória RAM
* **Formato de Troca:** JSON (Content-Type: application/json)
* **Versionamento:** Git & GitHub
